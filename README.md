# タイタンクルー（robot）

巨大ロボットの**中**にいる操縦士が、ロボット内部を走り回り、脚・腕・頭部砲・動力炉の操作盤に乗り込んで、1体のロボットを動かすゲーム。最大6人で、部屋番号を使ってオンライン協力ができる（ブラウザでも遊べる）。

- 画面の左半分：ロボットを横から見た断面図。中の機械のすき間に足場とはしごがあり、操縦士が歩いて登って移動する
- 画面の右半分：外を歩く巨大ロボット（3D）

Unity プロジェクト本体は `robot/` フォルダにあります。

## 動かし方

1. Unity Hub で `robot/` フォルダを開く（Unity 6000.4）
2. メニュー **Robot → ゲームのシーンを作成** を押す
   - `Assets/Game/Scenes/RobotGame.unity` ができて、開いた状態になります
3. ▶ 再生して **1人で出撃** を押す（オンラインの準備ができていれば「部屋を作る」「参加する」も使える）

## オンラインで遊ぶ（部屋番号）

1. だれか1人が **部屋を作る** を押す → 画面の下に **部屋番号** が出る
2. ほかの人はタイトル画面で部屋番号を入れて **参加する**
3. 試合が始まるまでは、みんな **待機室** にいる（歩いたり、はしごで中二階に登ったりできる）
4. 部屋を作った人（ホスト）が **試合開始** を押すと、全員が **ロボットの中心（胸の下の段）へ転送** される
5. 勝っても負けても、ホストが R を押すと待機室に戻る。途中から入った人はロボットの中に出る

ゲームの計算は部屋を作った人のブラウザ（またはPC）がする。部屋を作った人が抜けると、その部屋はなくなる。

つなぎ方は3通りあり、入っているパッケージと遊ぶ場所で自動で決まる（`Assets/Scripts/Net/OnlineRooms.cs`）。

| | ブラウザどうし直接（いまはこれ） | Unity Relay | 自分のサーバー（予備） |
|---|---|---|---|
| 使うとき | Web版（Multiplayer Services なし） | Multiplayer Services 2.4.1 が入っている | エディタ・PC版（Multiplayer Services なし） |
| 部屋番号 | 4けたの数字（例：`4821`） | 6文字の英数字（例：`K7M2QX`） | 4けたの数字 |
| 仲介 | PeerJS の無料の仲介サーバー（0.peerjs.com） | Unity Relay | `server/`（Node.js） |
| 準備 | いらない | パッケージと Unity Cloud のリンク | サーバーを動かす |
| Web版の公開 | GitHub Pages に置くだけ | GitHub Pages に置くだけ | `server` ごとサーバーに置く |

### ブラウザどうし直接（WebRTC ＋ PeerJS）

- 部屋を作ると、そのブラウザが PeerJS の無料の仲介サーバーに「titancrew-4821」のような名前で登録される
- 入る人はその番号で相手を探し、**ブラウザどうしが WebRTC で直接つながる**（直接つながらない回線では、PeerJS の無料の中継サーバー TURN を通る）
- Unity のパッケージやアカウントはいらない。GitHub Pages に置いた Web版だけでマルチができる
- マルチができるのは **Web版だけ**（エディタで試すときは1人用か、予備の自分のサーバー）
- 学校のように制限の強い回線では、仲介サーバーや WebRTC が遮断されてつながらないことがある
  （そのときは「仲介サーバー（PeerJS）につながりませんでした」などと出る）
- 中身：`Assets/Plugins/WebGL/PeerBridge.jslib`（ブラウザ側）と `Assets/Scripts/Net/PeerTransport.cs`（Netcode の通信方式）。
  PeerJS 本体（MIT ライセンス）は `robot/WebExtras/peerjs.min.js` にあり、`Robot → Web版をビルド` でゲームの横にコピーされる
  （見つからなければ unpkg / jsDelivr から読み込む）

### Unity Relay を使うとき（将棋のゲームと同じ）

学校のネットワークでは Unity のパッケージが取れないので、**家やスマホのテザリングなど制限のない回線で**やる。

1. **Window → Package Manager** → 左上の **＋** → **Install package by name...** に `com.unity.services.multiplayer`、Version に `2.4.1` と入れて Install
   - 学校の回線では取れないので、`manifest.json` には入れていない（入れると学校でプロジェクトが開けなくなる）
   - 入ると `HAS_RELAY` が定義され、Web版も Relay でつなぐようになる
2. **Edit → Project Settings → Services** で、Unity Cloud のプロジェクトにリンクする（将棋のゲームと同じアカウントでよい）
3. [Unity Cloud](https://cloud.unity.com/) で、そのプロジェクトの **Relay** を有効にする
4. メニュー **Robot → ゲームのシーンを作成** をもう一度押す（シーンとプレハブを本物の Netcode 用に作り直す。これをしないと NetworkManager が「Missing Script」になる）

## Web版を公開する（GitHub Pages）

将棋のゲームと同じやり方。

1. Unity Hub → **インストール** → このバージョンの歯車 → **モジュールを加える** → **Web Build Support** を入れる（最初だけ）
2. メニュー **Robot → Web版をビルド** を押す → `robot/Builds/Web` にできる
   - Gzip 圧縮 ＋ Decompression Fallback（GitHub Pages は Brotli に対応しないため）に自動で設定する
3. GitHub で公開用のリポジトリ（例：`robot-web`）を作り、`Builds/Web` の**中身**（`index.html`・`Build`・`TemplateData`・`peerjs.min.js` など）を **Add file → Upload files** でアップロードする
4. そのリポジトリの **Settings → Pages** で、Branch を `main`・フォルダを `/ (root)` にして Save
5. しばらくすると `https://（ユーザー名）.github.io/robot-web/` で遊べる。その URL を友だちに送る

注意：

- `index.html` をダブルクリックしただけでは動かない
- ブラウザのタブを裏に回すとゲームが止まる。**部屋を作った人はタブを開いたまま**にしておく
- 1人で遊ぶときはサーバーにつながない（通信なし）
- いまのところキーボード操作だけ（スマホのタッチ操作には対応していない）
- Web版では OS の日本語フォントが使えないので、`Assets/Resources/Fonts/ipagp.ttf`（IPA Pゴシック、IPAフォントライセンス v1.0。ライセンス文は同じフォルダ）を同梱している

### 予備：自分のサーバー（server/）

Multiplayer Services を入れないときは、Node.js（18 以上）のサーバーで中継する。1つのサーバーで Web版を配るのと部屋番号の中継の両方をする。

    cd server
    npm install
    npm start          # http://localhost:8080 で起動。robot/Builds/Web をそのまま配る
    npm test           # 部屋を作る・入る・中継・満員・抜ける の動作確認

- エディタ・PC版は、タイトル画面の **サーバー** の欄に URL を入れる（自分のPCなら `ws://localhost:8080/ws` のまま）
- 公開するときは、`server` フォルダと Web版を Node.js が動くサーバー（Render・Railway・VPS など）に置いて `npm start`
- 通信のきまりは `server/server.js` の先頭、Unity 側の通信は `Assets/Scripts/Net/WebSocketTransport.cs`

## 操作

| キー | 操縦席にいないとき | 操縦席にいるとき |
|---|---|---|
| A/D・左右の矢印 | 足場の上を歩く | 席ごとの操作（下の表） |
| W/S・上下の矢印 | はしごの前で登り降り | 席ごとの操作（下の表） |
| E | 近くの席に乗る／壊れた装置を直す／ダクトに入る | 席から降りる |
| Space | 火災の消火（連打） | アクション |
| Tab（押している間） | 内部の全体図 | 内部の全体図 |

ゲームパッド：左スティックで移動、A でアクション、B で乗る／降りる。

| 席 | 操作盤 | 操作 |
|---|---|---|
| 左脚・右脚 | スロットルレバー・速度計・両脚のレバー・曲がる向き | W/S かレバーをドラッグして倒す。両脚をそろえると前進、差をつけると曲がる。Space（かブレーキボタン）でレバーを 0 に |
| 左腕・右腕 | 狙いのダイヤル（敵の方向・射程）・パンチレバー・ガードボタン・ロケットパンチ | A/D かダイヤルのクリックで狙う。Space（か S・ドラッグ）でレバーを引き、引ききったら離すとパンチ。W 長押しでガード。F を2回でロケットパンチ |
| 頭部砲 | レーダー（敵の位置）・砲塔の向き | A/D かレーダーのクリックで砲塔を回す。Space 長押しで連射 |
| 動力炉 | 圧力計・タービン・動力計 | 針が緑の範囲のときに Space（+9）。ずれると +3。座っているだけでも少し回復 |

被弾すると、どこかの席で火災が起きて使えなくなります。その席まで走って Space 連打で消火。

## ダクト

はしごだと遠い場所どうしは、黄色いハッチの**ダクト**でつながっている。前で E を押すと、つながっている先のダクトから出てくる（行き先は選べない。約1秒）。

| ダクト | つながっている先 |
|---|---|
| 頭 | 腰 |
| 胸の上（左） | 左の手のひら（左腕の席） |
| 胸の上（右） | 右の手のひら（右腕の席） |
| 胸の下（左） | 左すね（左脚の席） |
| 胸の下（右） | 右すね（右脚の席） |
| 左足 | 右足 |

## 巨大な敵

外の世界には巨大な敵が1体だけいる（全高 約42m。タイタンは約34m）。体力を0にすれば勝ち。

ロボットを動かすだけでも大変なので、敵は少し弱めにしてある（体力 220、攻撃の間隔は 7～11 秒）。

- ゆっくり歩いてタイタンに近づき、近くまで来ると止まって攻撃する
- 攻撃の前には、**地面に赤い範囲が出る**。真ん中から赤く埋まっていき、埋まりきると攻撃が来る。範囲の外へ出ればよけられる
- **振り下ろし**（近いとき）：敵の正面の**扇形**（左右55°・38m）。6ダメージ。範囲から出るか、両腕でガード
- **足踏み**（近いとき）：敵のまわりの**円**（半径34m）。2.5ダメージ。まれに脚の油圧が切れる
- **大技 メガフレア**（試合開始から70秒後、そのあと90〜120秒ごと）：タイタンのいた場所に**大きな円**（半径18m）が出て、7秒ためてから大爆発（28ダメージ）。
  脚の係が急いで円の外へ歩かせよう
- **チャンスタイム**：メガフレアをためているあいだに **45 ダメージ**（パンチ2発・ロケットパンチ・必殺技など）を与えると、
  大技が止まって敵が9秒間倒れる。そのあいだは敵が攻撃せず、**ダメージ 1.5 倍**
- パンチは25（敵の体力の約1割）、ロケットパンチは80、頭部砲は1発1.5ダメージ。被弾すると、まれに火災や装置の故障が起きる

## ロケットパンチ（一度きりの切り札）

腕の席で **F を2回**（操作盤の「ロケットパンチ」ボタンを2回、ゲームパッドは Y を2回）押すと、ひじから先を飛ばす（動力 10）。

- 発射した人の画面は**全画面の一人称視点**（拳のすぐ後ろ）に変わり、拳を飛行機のように操縦する
  - **A / D**：左右に曲がる　**W / S**：上 / 下
- 敵に当てると **80 ダメージ**（パンチ強化中は 1.5 倍）。通り道のビルも壊す
- 当たるか8秒たつと、拳は爆発してなくなる
- **飛ばした腕は戻らない**。その試合のあいだ、3D のロボットも左の内部の絵も、その腕はひじから先がないまま
  （その腕の席には座れず、はしごで降りられず、ダクトでも行けない。その腕のパンチとガードも使えない）
- **撃った人は腕と一緒に飛んでいったので、その試合は観戦だけ**になる（外の画面が全画面になる）。次の試合からまた乗り込める
- 全員が観戦になると、ロボットを動かす人がいなくなって負け

## ガード

腕の席で **W を長押し**（操作盤の「ガード」ボタンを押し続けても、ゲームパッドは LB）すると、その腕を顔と胸の前で構える。

- 腕1本でダメージ 40% 減、**両腕で 80% 減**（足踏みの揺れは半分しか防げない）
- 振り下ろしをガードすると、火災や肩の配線切れも起きにくくなる（両腕ならほぼ起きない）
- ガード中はパンチできず、動力を少しずつ使う
- 敵が振りかぶると、腕の操作盤に「ガード！」と出る。左右の腕の係で声をかけ合って両腕で受け止めよう

タイタンは重いので、レバーを倒してもゆっくり加速し、戻してもすぐには止まらない。腕もゆっくり振る。

## 整備タスク

敵の攻撃を受けると、ロボットのあちこちの装置がまれに壊れる（時間がたつだけで勝手に壊れることはない。ガードすると壊れにくい）。
ロボットの操縦がメインなので、修理のミニゲームはさっと終わる簡単めにしてある。
壊れた装置には赤い「！」が付き、左上の一覧とミニマップにも出る。近くで E を押すとミニゲームが始まり、やり終えると直る。

| 場所 | 装置 | ミニゲーム | 壊れていると |
|---|---|---|---|
| 胸 | 冷却バルブ | A/D を交互に押してバルブを回す | 動力が早く減る |
| 左肩・右肩 | 腕の配線 | 同じ色の線をつなぐ（W/S と Space、クリックでも可） | **その腕がまったく動かない**（直すと動く） |
| 左もも・右もも | 脚の油圧 | 針が緑の範囲に入ったら Space | **その脚がまったく動かない**（直すと動く。敵の踏みつけで切れることがある） |
| 腰 | ヒューズ | 指定と同じ数字のヒューズを選ぶ | 頭部砲が撃てない |
| 頭 | 照準の調整 | 回る印が目標に重なったら Space | 砲撃が狙いからずれる |
| 腹 | 排熱ダクト | Space 連打でゴミを取る | 装甲がじわじわ減る |
| 左足 | 姿勢制御ジャイロ | A/D で印を真ん中の枠に入れておく | 歩くとふらついて曲がる |

装置の位置と内容は `Assets/Scripts/Core/Tasks.cs`、ミニゲームは `Assets/Scripts/Core/TaskUI.cs`、壊れたときの効果は `RobotState.cs` にある。

## エネルギーセル（やってもやらなくてもいい強化）

ロボットの中の遠い場所（手のひら・足・すね・頭）に、光る **エネルギーセル** がときどき出てくる（20秒ごとくらい、同時に2個まで）。

1. セルの近くで **E** を押すと拾える（持っている間は少し遅くなる。はしごもダクトも使える）
2. 体の真ん中の **動力炉**（胸の下の段）まで運ぶ。持っているあいだは動力炉の入れ口が光り、ミニマップにも印が出る
3. 動力炉のそばで **E** を押して入れると、ロボットが強化される（スコア +30）

| 色 | 強化 |
|---|---|
| 緑 | 装甲 +25 |
| 赤 | パンチ強化（20秒間、ダメージ 1.5 倍。拳から赤い火花） |
| 青 | 必殺ゲージ +40 |
| 黄 | 動力 満タン |

強化されると、外の画面に「強化！」と出て、3D のロボットの胸がその色に光る。
出る場所や効果の数字は `Assets/Scripts/Core/EnergyCells.cs`。

## ビルの破壊

街のビルは壊せる。

- タイタンが歩いてぶつかると踏み倒す（そのとき少し減速する）
- パンチの拳の先にあるビルは一撃で崩れる
- 頭部砲は3発で崩れる
- 必殺ビームの通り道にあるビルはまとめて崩れる
- 1棟崩すごとにスコア +40（敵が踏みつぶしたビルは点にならない）

リスタートすると元どおりに建て直される。

## 必殺技（胸のビーム）

敵に攻撃を当てると「必殺ゲージ」がたまる（右上の表示と、頭部砲の操作盤に出る）。

1. ゲージが満タンになったら、頭部砲の席で **F**（または操作盤の「必殺技」ボタン、ゲームパッドは Y）
2. 約2秒のため（胸の灯りが強く光る）のあと、胸から**胴の正面へ**太いビームが出る
3. 当たると敵に大ダメージ（70）。敵は攻撃を中断して、しばらくひるむ

砲塔の向きではなく胴の向きに撃つので、脚の係と声をかけ合って敵を正面にとらえよう（操作盤に「胴の正面に敵」と出る）。
