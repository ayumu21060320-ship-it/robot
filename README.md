# タイタンクルー（robot）

巨大ロボットの**中**にいる操縦士が、ロボット内部を走り回り、脚・腕・頭部砲・動力炉の操作盤に乗り込んで、1体のロボットを動かすゲーム。最大6人で、部屋番号を使ってオンライン協力ができる（ブラウザでも遊べる）。

- 画面の左半分：ロボットを横から見た断面図。中の機械のすき間に足場とはしごがあり、操縦士が歩いて登って移動する
- 画面の右半分：外を歩く巨大ロボット（3D）

Unity プロジェクト本体は `robot/` フォルダにあります。

## 動かし方

1. Unity Hub で `robot/` フォルダを開く（Unity 6000.4）
2. メニュー **Robot → ゲームのシーンを作成** を押す
   - `Assets/Game/Scenes/RobotGame.unity` ができて、開いた状態になります
3. ▶ 再生して **1人で出撃** を押す（オンラインの準備ができていれば「部屋を作る」「参加する」も使える）

## オンラインで遊ぶ（部屋番号）

1. だれか1人が **部屋を作る** を押す → 画面の下に6文字の **部屋番号**（例：`K7M2QX`）が出る
2. ほかの人はタイトル画面で部屋番号を入れて **参加する**
3. 試合が始まるまでは、みんな **待機室** にいる（歩いたり、はしごで中二階に登ったりできる）
4. 部屋を作った人（ホスト）が **試合開始** を押すと、全員が **ロボットの中心（胸の下の段）へ転送** される
5. 勝っても負けても、ホストが R を押すと待機室に戻る。途中から入った人はロボットの中に出る

通信は Unity の **Relay**（中継サーバー）を使う。ホストのパソコンの設定（ポート開放など）はいらない。
部屋を作った人が抜けると、その部屋はなくなる。

### オンラインの準備（最初に1回だけ）

学校のネットワークでは Unity のパッケージが取れないことがあるので、**家など制限のない回線で**やる。

1. Unity を開くと、`Packages/manifest.json` に入れた **Netcode for GameObjects（2.9.2）** が自動で入る
2. **Window → Package Manager** → 左上の **＋** → **Install package by name...** に `com.unity.services.multiplayer` と入れて Install
   - 入ると `HAS_NETCODE` と `HAS_RELAY` が定義され、`Assets/Scripts/Offline/` の代役は使われなくなる
3. **Edit → Project Settings → Services** で、Unity アカウントでログインし、**Unity Cloud のプロジェクトにリンク**する（無ければ新しく作る）
4. ブラウザで [Unity Cloud](https://cloud.unity.com/) を開き、そのプロジェクトの **Relay** を有効にする（小さい規模なら無料）
5. メニュー **Robot → ゲームのシーンを作成** をもう一度押す（シーンとプレハブを本物の Netcode 用に作り直す。これをしないと NetworkManager が「Missing Script」になる）
6. 試すときは、Web版かビルドしたものとエディタを同時に起動し、片方で「部屋を作る」、もう片方で部屋番号を入れて「参加する」

部屋の作成・参加のコードは `Assets/Scripts/Net/OnlineRooms.cs` にまとまっている。

## Web版（ブラウザで遊ぶ）

1. Unity Hub → **インストール** → このバージョンの歯車 → **モジュールを加える** → **Web Build Support** を入れる
2. メニュー **Robot → Web版をビルド** を押す → `robot/Builds/Web` にできる
3. `Builds/Web` の中身を zip にして、[itch.io](https://itch.io/) に「HTML」のゲームとしてアップロードする（公開範囲は「限定公開」にもできる）
   - `index.html` をダブルクリックしただけでは動かない（Web サーバーが必要）
4. できた URL を友だちに送れば、ブラウザだけで「部屋を作る」「参加する」ができる

注意：

- ブラウザは自分でホストを開けないので、Web版は **1人で遊ぶときも Relay の部屋を作る**（インターネットが必要）
- ブラウザのタブを裏に回すとゲームが止まる。**部屋を作った人はタブを開いたまま**にしておく
- Web版では OS の日本語フォントが使えないので、`Assets/Resources/Fonts/ipagp.ttf`（IPA Pゴシック、IPAフォントライセンス v1.0。ライセンス文は同じフォルダ）を同梱している

## 操作

| キー | 操縦席にいないとき | 操縦席にいるとき |
|---|---|---|
| A/D・左右の矢印 | 足場の上を歩く | 席ごとの操作（下の表） |
| W/S・上下の矢印 | はしごの前で登り降り | 席ごとの操作（下の表） |
| E | 近くの席に乗る／壊れた装置を直す／ダクトに入る | 席から降りる |
| Space | 火災の消火（連打） | アクション |
| Tab（押している間） | 内部の全体図 | 内部の全体図 |

ゲームパッド：左スティックで移動、A でアクション、B で乗る／降りる。

| 席 | 操作盤 | 操作 |
|---|---|---|
| 左脚・右脚 | スロットルレバー・速度計・両脚のレバー・曲がる向き | W/S かレバーをドラッグして倒す。両脚をそろえると前進、差をつけると曲がる。Space（かブレーキボタン）でレバーを 0 に |
| 左腕・右腕 | 狙いのダイヤル（敵の方向・射程）・パンチレバー・ガードボタン | A/D かダイヤルのクリックで狙う。Space（か S・ドラッグ）でレバーを引き、引ききったら離すとパンチ。W 長押しでガード |
| 頭部砲 | レーダー（敵の位置）・砲塔の向き | A/D かレーダーのクリックで砲塔を回す。Space 長押しで連射 |
| 動力炉 | 圧力計・タービン・動力計 | 針が緑の範囲のときに Space（+9）。ずれると +3。座っているだけでも少し回復 |

被弾すると、どこかの席で火災が起きて使えなくなります。その席まで走って Space 連打で消火。

## ダクト

はしごだと遠い場所どうしは、黄色いハッチの**ダクト**でつながっている。前で E を押すと、つながっている先のダクトから出てくる（行き先は選べない。約1秒）。

| ダクト | つながっている先 |
|---|---|
| 頭 | 腰 |
| 胸の上（左） | 左の手のひら（左腕の席） |
| 胸の上（右） | 右の手のひら（右腕の席） |
| 胸の下（左） | 左すね（左脚の席） |
| 胸の下（右） | 右すね（右脚の席） |
| 左足 | 右足 |

## 巨大な敵

外の世界には巨大な敵が1体だけいる（全高 約42m。タイタンは約34m）。体力を0にすれば勝ち。

ロボットを動かすだけでも大変なので、敵は少し弱めにしてある（体力 220、攻撃の間隔は 7～11 秒）。

- ゆっくり歩いてタイタンに近づき、近くまで来ると止まって攻撃する。**遠くからの攻撃はしない**
- **振り下ろし**（近いとき）：長く振りかぶってから爪を振り下ろす（9ダメージ）。画面に警告が出るので、そのあいだに離れるかガードする
- **足踏み**（近いとき）：地面を揺らして装甲を少し削る（4ダメージ）。ときどき脚の油圧が切れる
- パンチは12、頭部砲は1ずつダメージ。被弾すると火災や装置の故障が起きることがある

## ガード

腕の席で **W を長押し**（操作盤の「ガード」ボタンを押し続けても、ゲームパッドは LB）すると、その腕を顔と胸の前で構える。

- 腕1本でダメージ 40% 減、**両腕で 80% 減**（足踏みの揺れは半分しか防げない）
- 振り下ろしをガードすると、火災や肩の配線切れも起きにくくなる（両腕ならほぼ起きない）
- ガード中はパンチできず、動力を少しずつ使う
- 敵が振りかぶると、腕の操作盤に「ガード！」と出る。左右の腕の係で声をかけ合って両腕で受け止めよう

タイタンは重いので、レバーを倒してもゆっくり加速し、戻してもすぐには止まらない。腕もゆっくり振る。

## 整備タスク

手足の操縦とは別に、ロボットのあちこちの装置が時々壊れる（被弾したときも壊れることがある）。
壊れた装置には赤い「！」が付き、左上の一覧とミニマップにも出る。近くで E を押すとミニゲームが始まり、やり終えると直る。

| 場所 | 装置 | ミニゲーム | 壊れていると |
|---|---|---|---|
| 胸 | 冷却バルブ | A/D を交互に押してバルブを回す | 動力が早く減る |
| 左肩・右肩 | 腕の配線 | 同じ色の線をつなぐ（W/S と Space、クリックでも可） | **その腕がまったく動かない**（直すと動く） |
| 左もも・右もも | 脚の油圧 | 針が緑の範囲に入ったら Space | **その脚がまったく動かない**（直すと動く。敵の踏みつけで切れることがある） |
| 腰 | ヒューズ | 指定と同じ数字のヒューズを選ぶ | 頭部砲が撃てない |
| 頭 | 照準の調整 | 回る印が目標に重なったら Space | 砲撃が狙いからずれる |
| 腹 | 排熱ダクト | Space 連打でゴミを取る | 装甲がじわじわ減る |
| 左足 | 姿勢制御ジャイロ | A/D で印を真ん中の枠に入れておく | 歩くとふらついて曲がる |

装置の位置と内容は `Assets/Scripts/Core/Tasks.cs`、ミニゲームは `Assets/Scripts/Core/TaskUI.cs`、壊れたときの効果は `RobotState.cs` にある。

## ビルの破壊

街のビルは壊せる。

- タイタンが歩いてぶつかると踏み倒す（そのとき少し減速する）
- パンチの拳の先にあるビルは一撃で崩れる
- 頭部砲は3発で崩れる
- 必殺ビームの通り道にあるビルはまとめて崩れる
- 1棟崩すごとにスコア +40（敵が踏みつぶしたビルは点にならない）

リスタートすると元どおりに建て直される。

## 必殺技（胸のビーム）

敵に攻撃を当てると「必殺ゲージ」がたまる（右上の表示と、頭部砲の操作盤に出る）。

1. ゲージが満タンになったら、頭部砲の席で **F**（または操作盤の「必殺技」ボタン、ゲームパッドは Y）
2. 約2秒のため（胸の灯りが強く光る）のあと、胸から**胴の正面へ**太いビームが出る
3. 当たると敵に大ダメージ（70）。敵は攻撃を中断して、しばらくひるむ

砲塔の向きではなく胴の向きに撃つので、脚の係と声をかけ合って敵を正面にとらえよう（操作盤に「胴の正面に敵」と出る）。

## コードの構成

| ファイル | 役割 |
|---|---|
| `Assets/Scripts/Core/GameBootstrap.cs` | 全体の入口。左右2台のカメラ、接続メニュー、画面表示 |
| `Assets/Scripts/Core/Stations.cs` | 6つの操縦席の定義（名前・位置・種類） |
| `Assets/Scripts/Core/Ducts.cs` | ダクトの位置とつながり |
| `Assets/Scripts/Core/Tasks.cs` | 整備タスクの定義（場所・ミニゲームの種類・壊れたときの効果） |
| `Assets/Scripts/Core/StationUI.cs` | 操縦席に座ったときに出る操作盤 |
| `Assets/Scripts/Core/TaskUI.cs` | 整備タスクのミニゲーム |
| `tools/art/robot_layers.py` | ロボット全体の形（角ばったメカの輪郭）と、その内側の機械を3枚の大きな絵として描く。足場とはしごが体の中に収まっているかも確かめる（numpy・scipy・Pillow が必要） |
| `tools/art/lobby_room.py` | 出撃前の待機室の背景（壁・窓・座席・出撃ゲート）を1枚の絵として描く |
| `Assets/Scripts/Map/InteriorMap.cs` | ロボット内部の部屋と通路、歩ける場所の判定、内部の見た目 |
| `Assets/Scripts/Net/OnlineRooms.cs` | 部屋番号のオンライン（Relay で部屋を作る・部屋番号で入る） |
| `Assets/Scripts/Editor/WebBuild.cs` | メニュー「Robot → Web版をビルド」 |
| `Assets/Scripts/Map/ExteriorWorld.cs` | 外の世界（地面・ビル） |
| `Assets/Scripts/Net/RobotState.cs` | ロボットの状態とゲームの判定（ホストが計算して全員に配る） |
| `Assets/Scripts/Net/CrewPlayer.cs` | 操縦士1人ぶん（移動・入力・席の乗り降り） |
| `Assets/Scripts/Visual/RobotVisual.cs` | 外のロボット・ドローン・爆発などの見た目 |
| `Assets/Scripts/Editor/RobotGameSetup.cs` | 「Robot → ゲームのシーンを作成」メニュー |
| `Assets/Scripts/Offline/` | Netcode が入っていないとき（いまの1人用）に使う通信の代役 |
| `Assets/Scripts/Game.asmdef` | Netcode の有無で `HAS_NETCODE` を切り替える |

見た目はまだキューブや円柱の仮組みです。モデルができたら `RobotVisual.Build` と `InteriorMap.Build` を差し替えます。
